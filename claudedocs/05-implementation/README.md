# Implementation Specifications

Technical implementation guides and specifications.

## Purpose

This folder contains detailed technical specifications for implementing features, screens, and system components.

## Structure

- `screens/` - Screen-by-screen implementation details
- `features/` - Feature implementation specifications
- `mobile/` - Mobile-specific implementation guides

## Contents

Place implementation docs here:

- **Screen Specs** - Per-screen implementation details
- **Feature Guides** - Step-by-step feature implementation
- **Integration Guides** - How components connect
- **Platform Specifics** - Platform-specific considerations

## Key Files

| File | Purpose |
|------|---------|
| `PLATFORM_ADAPTATION.md` | Platform adaptation guide |
| `screens/*.md` | Individual screen implementations |
| `mobile/safe-area.md` | Mobile safe area handling |

## Guidelines

- Include code examples where helpful
- Reference related tests in `06-testing/`
- Link to architecture docs in `01-architecture/`
- Keep specs up to date with implementation
