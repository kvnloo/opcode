# Architecture Documentation

System design, ADRs, and architectural decisions.

## Purpose

This folder contains documentation about the system's architecture, design patterns, and technical decisions.

## Contents

Place architecture documents here:

- **Core Architecture** - System overview and component diagrams
- **ADRs** - Architecture Decision Records
- **Component Design** - Individual component specifications
- **API Design** - API structure and contracts
- **Data Models** - Database schemas and data flow

## Subdirectories

- `details/` - Deep-dive architecture documentation
- `adrs/` - Architecture Decision Records

## Guidelines

- Use diagrams where possible (Mermaid, PlantUML)
- Document the "why" not just the "what"
- Link related documents across folders
- Keep ADRs immutable once approved
