# Archive

Superseded and historical documentation.

## Purpose

This folder contains documentation that is no longer current but may be useful for historical reference.

## When to Archive

Move documents here when:

- A feature has been deprecated or removed
- Documentation has been superseded by newer versions
- Research has been concluded and incorporated elsewhere
- Sprint/iteration summaries are older than 6 months

## Structure

Organize archived content by date or topic:

```
99-archive/
├── YYYY-MM-DD/          # Date-based archives
├── deprecated-features/ # Feature-specific archives
└── legacy/              # Very old documentation
```

## Guidelines

- Add a note at the top of archived docs explaining why archived
- Don't delete - archive instead (maintains history)
- Periodically review for permanent deletion (annually)
- Keep archive organized and navigable
